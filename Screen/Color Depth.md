Color depth, also known as bit depth, refers to the number of bits used to represent the color of each pixel in a digital image or display. It determines the range of colors that can be displayed or stored in an image. The higher the color depth, the more colors can be represented.

Color depth is typically expressed in bits per pixel (bpp). For example:

- 1-bit color depth allows for 2 colors (usually black and white).
- 8-bit color depth allows for 256 colors.    
- 24-bit color depth (commonly known as True Color) allows for over 16 million colors.    
- 32-bit color depth includes an additional alpha channel for transparency information.    

Higher color depths result in more accurate and lifelike images, but they also require more storage space and processing power.
