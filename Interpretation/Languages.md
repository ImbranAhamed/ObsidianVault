Here’s a list of **purely interpreted languages** and **bytecode interpreted languages**:

---

### ✅ **Purely Interpreted Languages**

These languages **do not generate any intermediate code (like bytecode)**. The interpreter reads and executes the code **line-by-line** directly.

1. **Bash**
    
    - A shell scripting language commonly used in Linux and UNIX-based systems.
    
2. **Classic BASIC**
    
    - Early versions of BASIC that were interpreted without generating bytecode.
    
3. **Tcl**
    
    - A scripting language, commonly used in embedded systems and applications.
    
4. **Perl (older versions)**
    
    - Perl was originally interpreted in a pure manner, although modern Perl can also use bytecode compilation.
    
5. **Python (in some environments)**
    
    - Python can be interpreted directly in environments like the interactive shell (REPL) without creating bytecode files.
    
6. **Ruby (in some environments)**
    
    - Similar to Python, Ruby can be interpreted directly when used in an interactive mode.
    
7. **Scheme (in some implementations)**
    
    - Some implementations of Scheme (a Lisp variant) use pure interpretation.


---

### ✅ **Bytecode Interpreted Languages**

These languages **compile source code into an intermediate bytecode**, which is then executed by a virtual machine or an interpreter.

1. **Java**
    
    - Java source code is compiled into bytecode, which runs on the Java Virtual Machine (JVM).
    
2. **Python (with `.pyc` files)**
    
    - Python's CPython interpreter compiles source code into bytecode (`.pyc` files) before interpreting it.
    
3. **C# (with .NET Framework/CLR)**
    
    - C# code is compiled into Intermediate Language (IL) bytecode, which is executed by the Common Language Runtime (CLR).
    
4. **Ruby (with YARV - Yet Another Ruby VM)**
    
    - Ruby uses an internal bytecode interpreter (in the YARV implementation) for faster execution.
    
5. **JavaScript (in some engines)**
    
    - Modern JavaScript engines like V8 (Chrome) compile JavaScript into an intermediate bytecode before executing it.
    
6. **PHP (Zend Engine)**
    
    - PHP source code is compiled into bytecode by the Zend Engine before execution.
    
7. **ActionScript (Flash)**
    
    - ActionScript (used in Adobe Flash) is compiled into bytecode (SWF format) and executed in the Flash Player.
    
8. **Lua**
    
    - Lua source code is compiled into bytecode and executed by the Lua virtual machine.


---

### ⚙️ Key Difference:

- **Purely Interpreted Languages**: The interpreter **executes the code line-by-line** without generating any intermediate code.
- **Bytecode Interpreted Languages**: The code is **compiled into an intermediate bytecode** first, which is then executed by a virtual machine or interpreter.
