
It is short-hand notation for the syntax used to create a class variable using a default constructor and to set the state data property by property.

It is comma-de-limited list of specified values.

class Point
{
	public int X {get; set;}
	public int Y {get; set;}
	public Point(int n1, int n2)
	{
			X = n1;
			Y= n2;
	}

	public void DisplayStats()
	{
			Console.WriteLine(X);
			Console.WriteLine(Y);
	}
}


if we use the default constructor like Point() ,the developer need to assign value to the property one by one.

Point p1 = new Point();
p1.X = 10;
p1.Y = 20;

if we the custom custructor like Point(10, 20), it sets the state

Point p2 = new Point(10, 20);


if we use the object initialisation syntax, then

Point p3 = new Point{X = 10, Y = 20};    // implicit call to the default constructor
this will implicitly call the default constructor and sets the value to the specified properties


Point p3 = new Point( ){X = 10, Y = 20};    // Explicit call to the default constructor
