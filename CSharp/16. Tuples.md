Construct used to return multiple values from a function (refer out parameter)

**Syntax**:

(int, string, int) values = (1, "Imran", 12);

var values = ("imran", 20, "khan");

Compiler assigns each property the name "**ItemX**"

(string, string) name = ("Imran", "khan");

Console.WriteLine(name.Item1);
Console.WriteLine(name.Item2);

**Allowed to assign custom names to the property on either side,**
**But the compiler ignores the name assigned on the right side**

(string firstName, string lastName) name = (fName: "Imran", lName: "Khan");
Console.WriteLine($"{name.firstName}");
Console.WriteLine($"{name.lastName}");


**Nesting:**

(int, (string, int)) pair = (20, ("Imran", 20));


**Unpacking:**

int x;
string name;

(x, name) = name;       // decalred before
Console.WriteLine($"{x)"});
Console.WriteLine($"{name)"});
 or
 
(int x, string name) = name;   //declaration and assignment
Console.WriteLine($"{x)"});
Console.WriteLine($"{name)"});
or

(int x, name) = name;     // mixing decalred and assignment
Console.WriteLine($"{x)"});
Console.WriteLine($"{name)"});
