Used to initialisse the state of the object at the time of its creation

-  Default Constructor
-  Custom Constructor

**Default Constructor : 

The default constructor is provided built in by the compiler.
It is destroyed as soon as a new custom constructor is created.

class Product
{
	// fields
	public int productId;
	public string productName;

	//default constructor
	public Product()
	{
	
	}
	
}


**Custom Constructor: **

provide a number of ways to create an object at the time of declaration


class Product

	public string productName;

	//default constructor
	public Product()
	{
	
	}

	public Product(int id) =>this.productId = id;

    public Product(string name) => this.productName = name;

	 public Product(int productId, string name) 
	  {
				  this.productId = id;
				  this.productName = name;
	  } 
	
}


**Constructor Chaining**:

Designate the constructor which has the most number of parameters as the master constructor.
And delegate the work to the master consturctor from the slave constructor using the 'this' keyword.


class Product
{
	// fields
	public int productId;
	public string productName;

	//master constructor
	public Product(int productId, string productName)
	{
			this.productid = productId;
			this.productName = productName;
	}

	public Product(int productId): this(productId, "")
	{
	
	}

	public Product(string productName): this(0, productName)
	{
			
	}
	
}

How does the chaining works ? when anyone of the the slave constructors is invoked during the object creation, it control transfers to the master constructor along with the required arguments.
After the master constructors has constructed the object, the control returns or flow backwards to the originally called slave constructor to execute its code if any.


**Better Approach: **  (using optional arguments)

class Product
{
	// fields
	public int productId;
	public string productName;

	//default constructor
	public Product(int productId = default, string productName = "")
	{
	
	}
	
}


Now , the constructor can be called either of the following ways:

Product myPrd = new Product();
Prouduct myPrd1 = new Product(1);
Product myPrd2 = new Product("Pencil");
Product myPrd3 = new Product(1, "Pen");

*Note:*  In constructor chaining, the control goes to  constructor which is called at the time of object creation, but the instantly, the control transfers to the chained constructor. The control transfers to the originally called constructor only after the chained constructor finished it execution.
