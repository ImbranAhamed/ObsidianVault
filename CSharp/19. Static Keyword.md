
Members decorated with static keyword are created only once in the memory or only one copy exists in the memory.

An Instance member can access the static member directly;
An static member can't access the instance member directly, but can indirectly

Static keyword can be applied to the following:

-  Data of class
-  Method of a class
-  Properties of a class
-  Constructor
-  Entire Class Definition

**Defining Static Data fields**:

class Account
{
	// static point of data
	public static double **currentInterest**;

	// Instance level data
	public double currentBalance;
	
}


**Defining static Methods:**

class Account
{
	// static point of data
	public static double **currentInterest**;

	// Instance level data
	public double currentBalance;

	// Static methods
	public static void SetInterest(double interest) => interestRate = interest;

	public static int GetInterest() => interestRate;
	
}

**Defning Static Constructor:**  (does not contain access modifiers, can't be overloaded, called by clr only once, it is called before any instance constructor)

class Account
{

	static Account()
	{
			currentInterest = 4;
	}
	// static point of data
	public static double **currentInterest**;

	// Instance level data
	public double currentBalance;
	
}

**Defining a Static Class:**

static class should contain only static members.

static class UtilityClass
{
   // static members...
}

**Defining Static Imports:**

using **static** System.Console  // importing the static members of the Console class in the System namespace.

here, the System - namespace
                   Console - Class

*Note:*

-  A static class or a class declared as class should only contain or can have only static members
-  A regular class or normal class can have static and non-static members together.
