**Variable Decalration**:

DataType identifier;

int num1;
num1 = 10

int num1, num2, num3;
int num1 = 10, num2 = 20, num3  =30


**Default literal**:

int userAge = new int();
int userAge = new();
int userAge =   default;

**Implicitly typed variable:**

var variableName = value;  (value must be given at thet time of declaration, because value is used to infer the type of variable)
var variableName;  (not allowed)

- Can't be used as return value or parameter type
