If you want a property that:

1. Can be set only during construction
2. Is read-only afterwards

- then modern C# offers three common approaches.

**Using a backing field:**

private readonly string _empSSN;

public string EmpSSN => _empSSN;

public Employee(string ssn)
{
    _empSSN = ssn;
}

**Using a get-only auto-property:**

public string EmpSSN { get; }

public Employee(string ssn)
{
    EmpSSN = ssn;
}

**Using an init property (C# 9+):**

public string EmpSSN { get; init; }

which allows:

var emp = new Employee
{
    EmpSSN = "123"
};

but prevents modification later.

For ASP.NET Core and modern C#, the second approach (public string EmpSSN { get; }) is usually the cleanest way to model immutable state.
