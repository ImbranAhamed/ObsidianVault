
Encapsulation provides a way to preserve the **integrity of an object's state data.**

Encapsulation cap be done in two techniques:

- Traditional accessor and mutators methods 
- Using properties

**1. Traditional Approach**

This defines the accessor methods which returns  the object's state and mutator method which modifies the object's state

class Employee
{
    private int _empId;
    private string _empName;
    private double _empSalary;

    public Employee(int empId, string empName, double empSalary)
    {
        this._empId = empId;
        this._empName = empName;
        this._empSalary = empSalary;
    }


    // Traditional getters and setters
    public string GetName() => this._empName;
    public void SetName(string empName)
    {
        if(empName.Length < 15)
        {
            System.Console.WriteLine("Name error");
        }
        else
        {
            this._empName = empName;
        }
    } 
}

Problem: Requires pair of accessor and mutator methods for each state decalred in the class
