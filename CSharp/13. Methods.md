**Method Parameters**:
- Pass by value
- Pass by reference

All value types ae passed by value 
All refernce types are passed by reference except the string type (its passed by value even though its a reference type)

- none - passed based on the variable type (reference or value)
- ref - passed by reference
- in - passed in read-only mode (ref pararmeter is passed as read-only)
- out - the called function must assign the value for the out parameter variable.
- params - pass variable number of arguments
- optional parameter
- named arguments
